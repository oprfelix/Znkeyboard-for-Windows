ZnKeyboard for Windows 使用说明
================================

选中任意程序里的文字，按快捷键，用 AI 润色或翻译成目标语言，确认后替换原文。

一、第一次安装
1. 安装 .NET 10 桌面运行时（每台电脑只需装一次）：
   打开 https://dotnet.microsoft.com/download/dotnet/10.0
   在「.NET Desktop Runtime 10.0」一栏下载「Windows x64」安装程序并安装。
   （没装就直接运行的话，Windows 也会弹窗提示并给出下载链接。）
2. 把压缩包里的 ZnKeyboard.exe 放到一个固定的文件夹，例如「文档\ZnKeyboard」，然后双击运行。
3. 如果出现「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。
   这是因为程序没有购买代码签名证书，只在第一次出现。

二、设置
运行后，屏幕右下角托盘区会出现 ZnKeyboard 图标（可能在「^」里），设置窗口会自动打开：
- 服务商：Google Gemini，或 DeepSeek
- API Key：填好后点「保存」。Key 保存在本机的 Windows 凭据管理器里。
- 模型、翻译成：按需选择
- 通用 → 勾选「开机自动启动」，以后开机就会自动运行

三、使用
方法一：在输入框里选中文字（鼠标拖选、双击，或 Ctrl+A），旁边会出现小按钮「✨ 润色 | AI 翻译为 EN ▾」，点一下即可。
方法二：在任意程序里选中文字后按快捷键：Ctrl+Alt+R 润色，Ctrl+Alt+T 翻译。
然后鼠标旁出现结果卡片：回车 替换原文，Esc 取消，Ctrl+C 复制。
- 翻译时，卡片标题里的「AI 翻译为 [英语 ▾]」可以直接换语言，会马上重新翻译，并记住这次的选择。
- 小按钮上的「EN ▾」也可以切换语言；右键托盘图标同样可以切换。
- 快捷键可以在设置里改：点击快捷键，再按下新的组合键。双击托盘图标打开设置。
- 不想要小按钮的话，在设置里取消「选中文字后显示按钮」。

四、注意
- 润色和翻译时，选中的文字会发送给你所选的 AI 服务商，请按公司规定处理敏感内容。
- 以管理员身份运行的程序（比如部分安装程序）里的文字无法被替换，这是 Windows 的安全限制。
- 设置保存在 %APPDATA%\ZnKeyboard\settings.json。
- 遇到问题时：右键托盘图标 →「打开诊断日志」，把 debug.log 发给维护人。日志只记录操作和判断结果，不包含任何文字内容。
